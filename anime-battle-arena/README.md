# Anime Battle Arena

Gioco web locale per Lamine e Bassirou. Apri `index.html` nel browser.

Modalità: Asta classica, Tre carte, Multiverso. Ogni nuova partita parte con 20 monete a testa. Il primo offerente si alterna. Le carte scelte in modalità Tre carte restano vincolate al giocatore per l'asta corrente.

## Pubblicazione
Per pubblicare con GitHub Pages, configura Pages sul branch `anime-battle-arena` e cartella root, oppure distribuisci la sottocartella `anime-battle-arena` su un hosting statico. Non è necessario un backend.

## Nota
I valori di potenza sono indicativi e non costituiscono una classifica canonica ufficiale. Il gioco è pensato per due giocatori sullo stesso dispositivo.
